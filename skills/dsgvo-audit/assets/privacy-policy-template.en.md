# Privacy Policy — modular template (English version of `datenschutzerklaerung-template.md`)

**Use**: For websites with an English language version (Art. 12(1) GDPR: information in a form the addressee understands — a German-only policy on an English-targeted site is a 🟠 finding). This file mirrors the German template **module for module and number for number**, so both versions stay in step: delete the same modules, fill the same `[PLACEHOLDER]`s. The German version remains authoritative; say so in section 21. Keep the German norm names where English readers will meet them in German law (TDDDG, BDSG, DDG); GDPR articles are cited as "Art. … GDPR".
